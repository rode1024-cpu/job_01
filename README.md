# MD 공고 체크

이커머스 MD 이직 조건(과장급 5~8년, 카테고리·지역·연봉·조직 분리 등)으로 채용공고를 판정하고,
저장한 공고의 마감과 지원 후 팔로업을 알려주는 웹앱이에요. 서버 없이 브라우저에서만 돌아가요.

## 쓰는 법
1. `index.html`을 브라우저로 열어요. 알림과 오프라인 캐시는 https 또는 localhost에서만 되니, 폰에서 쓰려면 GitHub Pages 같은 곳에 올려 주세요.
2. 공고 텍스트를 붙여넣고 "판정하기". 여러 공고는 사이에 `=====` 한 줄을 넣으면 점수순 비교표가 나와요.
3. 마음에 들면 "공고함에 저장", 마감일과 상태를 관리해요.

## 알림 한계
- 브라우저 알림은 앱이 열려 있을 때만 떠요(서버 푸시가 없어요).
- 앱을 닫고도 받으려면 공고함의 "캘린더(.ics)"를 폰 캘린더에 넣어 두세요. D-3, D-1, 당일 9시에 울려요.

## 판정 방식
규칙(키워드) 기반이라 참고용이에요. 항목별 배점: 직무 15, 경력 5, 카테고리 20, 업무 15, 지역 15, 연봉 10, 조직 분리 10, 회사 규모 10.
- 제외 카테고리 주력, 경력 3년 이하/10년 이상, 출퇴근 불가 지역은 탈락(패스, 최대 35점).
- 70점 이상 지원 추천, 50~69 검토 후 지원, 그 미만 패스.
- 공고에 없는 항목은 감점 대신 중간 점수(60%)를 주고, 확인 질문으로 넘겨요. 연봉이 회사내규면 연봉 범위 질문이 항상 들어가요.
- 출퇴근 시간은 부천 기준 대략치라 [검증 필요]예요.
- 조건은 `engine.js` 상단의 키워드 목록에서 바꿀 수 있어요. 수정 후 `node test.js`로 확인하세요.
